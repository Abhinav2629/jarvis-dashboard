Settings

Jarvis keeps your data in a private GitHub repo. This device needs a GitHub access token to read it and to start runs. The token stays on this device only.

How to create the token (2 minutes, once per device or share one)
  1. Open GitHub → Fine-grained token (sign in as the repo owner).
  2. Repository access: Only select repositories → choose jarvis.
  3. Permissions → Repository: Actions = Read and write, Contents = Read-only.
  4. Expiration: up to 1 year. Generate, copy, paste above.
